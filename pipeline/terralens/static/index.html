A LITTLE GUIDANCE

Start with a question.

01

Choose your study area.

Each library contains real aerial imagery and reference vectors for a small geographic sample.

02

Describe what you need.

Try an example, then add a supported spatial relationship such as “within 20 metres of roads.” More complex questions require the configured conversation service.

03

Inspect the evidence.

Select a result to see source imagery, coordinates, detection boxes and the checks behind the finding. Image similarity describes a scene; it does not prove an object exists.

04

Take your findings with you.

Export the full run as GeoJSON, including source metadata and unresolved candidates. A sample does not establish complete geographic coverage.
